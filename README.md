## 📖 Description | الوصف

### English

This project aims to predict customer churn in the telecommunications industry using Machine Learning techniques. Customer churn refers to customers who stop using a company's services. By analyzing customer demographic and usage data, the project identifies patterns associated with churn and builds predictive models to help telecom companies improve customer retention.

The project includes:

* Data collection and preprocessing
* Feature engineering and encoding
* Data scaling and normalization
* Model training and evaluation
* Comparison of different machine learning algorithms

### العربية

يهدف هذا المشروع إلى التنبؤ بالعملاء المتوقع مغادرتهم لشركة الاتصالات باستخدام تقنيات تعلم الآلة. ويُقصد بمصطلح **Churn** العملاء الذين يتوقفون عن استخدام خدمات الشركة. يعتمد المشروع على تحليل بيانات العملاء الديموغرافية وبيانات الاستخدام لاكتشاف العوامل المؤثرة في ترك الخدمة وبناء نماذج تنبؤية تساعد شركات الاتصالات على تحسين الاحتفاظ بالعملاء.

## 🚀 Usage | كيفية الاستخدام

### English

1. Place the dataset files in the project directory:

   * telecom_demographics.csv
   * telecom_usage.csv

2. Launch Jupyter Notebook.

3. Run all notebook cells sequentially.

4. The notebook will:

   * Merge datasets
   * Preprocess features
   * Encode categorical variables
   * Scale numerical features
   * Train classification models
   * Evaluate model performance
